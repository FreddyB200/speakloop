# Roadmap

| Milestone | Deliverable | Exit criterion |
|---|---|---|
| **M0 Foundations and proof** | Repo, data contracts, transcription benchmark, rubric and prompts v1 | An audit run on real audio that feels useful and fair; transcription backend chosen with data |
| **M1 MVP: audit loop** | `speakloop audit <audio>` produces a report with metrics, 5 patterns and a goal; two tracks if available | Three audited sessions form the baseline |
| **M2 Items and Anki** | Findings become items and Anki cards; enrichment with openly licensed data | After a session, the new cards appear in Anki |
| **M3 Practice modes** | Shadowing with a synthetic native voice and mispronounced-word detection, 4/3/2, interview question bank and scripts for an AI interviewer | A full cycle without leaving the terminal |
| **M4 Progress** | Trends against the baseline, weekly review, log of real interviews | A weekly report that shows a trend |
| **M5 Recorder** | Two-track capture (microphone and system audio) with a hotkey | A mock interview with measured response latency |
| **M6 Pronunciation (research)** | Phoneme-level prototype | A decision on whether to continue |
| **M7 Ecosystem** | Plugins, packs per domain and native language, documentation, possibly a local web UI | Someone other than the author installs and uses it |

M0 to M2 deliver real value quickly; the recorder is deferred because existing tools already work for recording.
